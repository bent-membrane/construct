# 构造

> 一张被压弯的膜，一根断掉的绳，和一场永不停止的扫射。

一本关于宇宙结构的独立书稿，附可复现的数值实验。

书稿以膜、绳、粉尘为基本对象，建立一套宇宙模型的图像，并把其中可量化的部分写成数值沙盘。所有脚本可运行、可改参数；观测数据、几何结论与解释机制分开陈述，便于逐条核对。本书稿为独立整理，非期刊投稿。

## 怎么读

书稿把每个论断分三层陈述：

- **数据** —— 观测值：φ、ΔS、块数、速度
- **结论** —— 从数据推出的几何判断
- **机制** —— 解释模型

分开陈述是为了让每一层单独接受检验。机制层最容易被修正，也最需要先被检验。

书稿中保留了若干"计算之后废止"的路径，连同废止原因一并记录，而不删去。

## 基本假设

这套框架从以下前提出发。它们是假设，不是结论：

1. **不单独引入暗物质粒子。** 弱透镜反演得到的"质量"被解释为膜的形变，而非物质分布。
2. **观测记录保留时空坐标。** 需要剥离的是建模推演那一层，观测数据本身不受影响。
3. **膜面内不设额外束缚力**，张力沿第四维方向。
4. **并合之后的回程由引力梯度解释**，不引入额外的能量收支。
5. **辫群结构决定解绑方式。** B2 每层路径唯一；B3 从长度 3 开始出现分叉。这一结果由群结构直接给出，不含手调参数。
